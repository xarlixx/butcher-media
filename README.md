# butcher-media

Видео для сайта [butcher.studio](https://www.butcher.studio). Сайт берёт их отсюда через jsDelivr.

| Файл | Где на сайте | Размер |
|---|---|---|
| `home-heart.webm` | главная, блок с сердцем | 1,2 МБ |
| `contacts-cookie.webm` | Contacts, видео с печеньем | 2,1 МБ (облегчённая версия, оригинал 9,4 МБ) |

Ссылка для сайта:
`https://cdn.jsdelivr.net/gh/xarlixx/butcher-media@v1/<файл>`

Чтобы заменить видео: загрузить новый файл, поставить новую метку (`v2`, `v3`…) и поменять в ссылке на сайте `@v1` на новую метку. Если файл с тем же именем просто перезаписать, jsDelivr ещё долго будет отдавать старый.
